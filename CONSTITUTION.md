# Constitution

1. Game stays playable: after any change, the page loads with no console errors and both cars drive.
2. No build step: plain HTML, CSS and JS served as static files.
3. Smallest change that works; match the existing style in `main.js`.
4. Keep `window._CAR_DEMO` working; the tests depend on it.
5. Never commit `node_modules/`, `.vs/`, `agents/` or secrets.
6. Commit or push only when asked.
7. Keep these instruction files short: one line per rule, no duplication.
